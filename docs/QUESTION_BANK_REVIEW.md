## 二、重要背景：岗位体系已变化（必读）

## 三、与系统不一致的问题

### 3.1 「雷达图维度」列与后端报告维度不匹配

- 题库写法（3 维）：技术正确性；知识深度；逻辑严谨性
- 后端报告实际维度（**4 维**）：`tech_score` 技术能力 / `logic_score` 逻辑思维 /
  `expression_score` 表达沟通 / `match_score` 岗位匹配度

**修改要求**：该列改为与后端一致的 4 个维度（技术能力/逻辑思维/表达沟通/岗位匹配度），
用于 P3 评分时对齐标准；或直接删除该列（评分以 P3 为准）。

### 3.2 「面试阶段」列（一面/二面/三面）系统没有对应概念

后端面试流程是 **1 道开场题 + 6 轮追问（共 7 轮）**，不存在"技术一面/二面/三面"的分面流程。

**修改要求**：保留该列作为选题参考无妨，但请知悉 P2 抽题时按「开场题 → 追问」两段使用：
- 开场题（第 1 题）建议从**基础题**中抽取；
- 追问（第 2~7 题）结合「追问考查锚点」生成。

### 3.3 「系统全流程测试用例」sheet 与已完成后端严重脱节（重点）

该 sheet 的 53 条用例是按一套"想象中的系统"写的，其中大量功能与已完成的后端不符：

| 用例假设 | 后端实际 |
| :--- | :--- |
| TC-001/002 手机号+验证码注册登录 | 账号密码（username + password）注册登录，无手机号无验证码 |
| TC-005/025/036 软件测试岗位相关 | 测试岗已开放，但岗位清单未最终确定，用例需按岗位接口动态写 |
| TC-006~009 难度选择功能 | **无此功能**（后端按轮次出题，没有难度筛选） |
| TC-011 语音转文本接口 | 无 ASR 后端接口，语音转写由前端浏览器 Web Speech API 完成 |
| TC-018/035/045/046 学习推荐/练习计划 | 系统**无此功能** |
| TC-026 报告导出 | 无导出接口 |
| TC-029~031 语速/清晰度/自信度情感分析 | 报告只有 4 维评分 + 评语/优缺点/建议，无语音情感分析 |

**修改要求**：该 sheet 请参照后端实际能力重写，权威依据：
`backend/tests/test_api.py`（后端 16 个真实用例，已覆盖全流程）与 `docs/API.md`（接口文档）。
RAG 相关的用例（TC-021/022/043/044 等）请保留，但要按 P2 的实际 RAG 实现方式改写。

## 四、内容质量问题

### 4.1 锐捷业务场景占比过高（76%，需确认意图）

- 实际扫描：150 题中 **114 题**（Java 后端 41、Web 前端 40、软件测试 33）的题干或
  「锐捷场景」列出现"锐捷云课堂 / 锐捷设备管理平台 / 锐捷课程报名"等锐捷业务场景
- 本项目是面向计算机学生的**通用** AI 模拟面试系统，并非锐捷校招系统

**请确认**：这是刻意做的锐捷定向训练题，还是 AI 生成时被带偏？
- 若**有意为之**：请回复确认，P2 会在 Prompt 中保留该设定；
- 若**并非有意**：请将题干中的锐捷场景改写为通用场景（如"高并发课程报名系统"→"高并发业务系统"），
  「锐捷场景」列同步改为通用行业场景或删除。

另外，「岗位题库统计表」中"关联锐捷业务场景题数"一列写的是 40/40/40（合计 120），
与各 sheet 实际值（41/40/33，合计 114）**对不上**，修改后请一并更新统计表。

### 4.3 标准回答范例存在断裂拼接（13 题，必修）

以下题目的「标准回答范例」中有句子断裂/拼接残留（范例会被作为参考答案喂给评分模型）：

### 4.4 追问锚点 JSON 键名不统一（35 题，必修）

「追问考查锚点」列是 JSON 字符串，但键名存在两套写法：

| 键组合 | 题数 |
| :--- | :--- |
| 正确追问 + 引导追问 | 46 |
| 正确追问 + 引导追问 + 深度追问 | 69 |
| 正确追问 + **实践追问** + 深度追问 | **35** |

使用"实践追问"键的题号：
- Java 后端（15）：BE-017~022、BE-033~035、BE-042~045、BE-049~050
- Web 前端（12）：FE-018~022、FE-033~035、FE-043~045、FE-050
- 软件测试（8）：QA-020~022、QA-034~035、QA-044~045、QA-050

P2 解析 JSON 时按固定键名取值，键名不统一会导致这 35 题的引导追问丢失。

**修改要求**：统一为 **`正确追问` / `引导追问` / `深度追问`** 三个键
（深度追问缺省的题补上或允许为空字符串）。
