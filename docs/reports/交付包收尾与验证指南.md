## 二、需要博士做的三件事

### 1. 验证包能独立跑起来（最重要）

**第 1 步**：先关掉本机正在运行的服务（避免 8001 / 8003 / 8005 / 5273 端口冲突）。

**第 2 步**：把交付包里的 `ai-interview-system` 整个目录拷到另一个位置，模拟评委解压后的场景：

```bash
cp -r "d:/外包竞赛/project/交付包-20261009/ai-interview-system" "D:/_verify/ai-interview-system"
```

**第 3 步**：双击 `D:\_verify\ai-interview-system\backend\start.bat`，对照窗口输出：

- `[1/5]` 至 `[5/5]` 各步骤依次打印；
- 若 Python 环境缺依赖，脚本会自己 `pip install`（走国内源），**首次会装 RAG 依赖约 2.5GB**，耗时长属正常；
- 末段会打印本机与局域网的访问地址。

**第 4 步**：浏览器访问 <http://localhost:8005/health>，确认三个字段：

| 字段 | 期望值 | 含义 |
| :--- | :--- | :--- |
| `bank_loaded` | true | 题库已加载 |
| `scorer_ready` | true | 评分器已预热（后台线程，约数十秒） |
| `llm_configured` | true | 密钥已读到 |

该接口恒定返回 200，**要按字段判断，不能只看状态码**。

**第 5 步**：访问 <http://localhost:8001>，走一遍完整流程：

1. 注册一个账号（选岗位、填学号）；
2. 开一场面试，前两题用文字答，找一题**用一次语音**（验证转写与表达读数）；
3. 答满或主动结束，看报告页：五维分数、雷达图、成长档案与考后复盘是否都出来。

报告能出分就说明 DeepSeek 密钥通了；语音有转写就说明 SenseVoice 正常；成长档案有内容就说明引擎链路完整。

**第 6 步**：验证完把 `D:\_verify` 整个删掉。

> 如果手头有第二台机器（或虚拟机），在它上面解压运行一次更有价值——那才是评委的真实场景，能顺带验证「依赖自动安装」这条路。
