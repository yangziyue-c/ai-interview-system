## 一句话

P5 于 2026-09-25 交付的第三版对话层已接入本项目。出题、追问、五维评分这条主链的用法不变，新增了两条**已经能用**的链路：语音转写与成长档案。专项练习、参考答案、复盘清单三个出口暂未接，等前端做对应界面时一并接。

## 一、这一版交付了什么

自上一批（2026-09-23）以来，对话层经历了九批迭代，端点从 6 个扩到 10 个：

| 新增端点 | 用途 |
| :--- | :--- |
| `POST /asr` | 语音转写：音频进，文字 + 时长 / 停顿 / 语速 / 音量等表达指标出 |
| `POST /growth` | 成长档案：喂若干场的档案摘要，取错题本 / 考点地图 / 历史成绩 / 提升路径 |
| `POST /practice` | 专项强化练习：从已交卷的成绩单挑薄弱项开练习场 |
| `POST /model_answer` | 参考答案与考点讲解：考生出口 |

`/finish` 与 `/result` 新增两个顶层键：`digest`（成长档案摘要，给集成方存档用）与 `review`（复盘清单，给考生看）。`core/` 下新增 7 个能力模块（语音、知识库检索、学习资源、练习、成长档案、复盘、参考答案）。

契约总体是**只增不改**：既没有字段改名，也没有字段删除。`A11_RAW_DETAIL` 默认收口到脱敏档，`/finish` 与 `/result` 的 `raw` 只剩占位键，得分点原文不再出门。

## 二、本项目接了什么、没接什么

| 能力 | 状态 | 说明 |
| :--- | :--- | :--- |
| 主链（出题 / 追问 / 评分） | 已接（上一版） | 开关 `DIALOGUE_ENGINE=a11`，10 题制，整场委托 |
| 语音转写 | **本轮新接** | `POST /api/v1/uploads/audio/asr`，一次调用同时返回文本与 `audio_url` |
| 成长档案 | **本轮新接** | 每场 `digest` 落库进 `reports.digest`；`GET /api/v1/reports/archive` 取四视图 |
| 学习资源推荐 | 间接可用 | 素材已按题目 ID 平铺到 **5012 条**（4021 篇真题范文 + 991 篇**明确标注**的示范作答），内容随 `/finish` 的明细返回（`/health` 的 `resource_kps=25` 是**考点数**，不是素材覆盖度） |
| 专项练习 `/practice` | 未接 | 等前端做练习入口时一并接 |
| 参考答案 `/model_answer` | 未接 | 等前端做讲解界面时一并接 |
| 复盘清单 `review` | 未接 | `/finish` 已返回，前端渲染即可，后端无需额外工作 |

没接的三个都是「给考生的出口」：没有界面就没有用户，现在接进主后端等于把契约先冻一遍、界面做完可能还要再对一次。`digest` → `/growth` 这条链已经通了，是它们的基础。

## 五、怎么用

```bash

pip install modelscope
python -c "from modelscope import snapshot_download as d; \
  d('BAAI/bge-reranker-v2-m3', local_dir='.hf_cache/bge-reranker-v2-m3')"
python -c "from modelscope import snapshot_download as d; \
  d('Systran/faster-whisper-small', local_dir='.hf_cache/faster-whisper-small')"

# 启用引擎（不设则走原链路）

# 然后照常双击 backend/start.bat
```

语音转写的演示路径：在面试页按住话筒说话，松开后自动上传并转写，文本填进输入框，考生可修改后再发送。

## 六、已知边界

- **语音转写有内存门槛**：引擎要求空闲内存达标才加载模型（本项目按实测设为 800MB）。整机 15.2GB 且同时跑着 reranker（约 2.3GB）时比较紧，**演示前建议关掉浏览器、Steam 这类程序**；内存不足时转写返回 503 并说明原因，不会硬加载到 OOM。
- **情感模型的标签别当结论**：权重已由 P5 提供并部署成功（SHA256 逐文件核对一致），但它是**英语表演情绪**数据训的，**中文上不可信**（实测中文 3/3 判 `hap`）。演示口径是「有情感分布，中文看波动」，**不要说「情感识别很准」**。
- **转写有错字是正常形态**：模型 small + int8 量化，设计上就是让考生确认修改后再发送。
- 引擎模式下失败**不回落原链路**，一律返回 503（错误码 50300），避免一场面试中途换评分口径。
- 两种链路的分数不可直接比较；成长曲线已带 `engine` 字段并支持按链路筛选，前端暂未接入。
