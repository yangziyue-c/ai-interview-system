# A11 引擎落地 P1 本机 · 前端对接注意事项（给 4 号）

> 2026-10-01。AI 对话层引擎（8005）从 5 号的机器移交到 1 号本机独立部署。
> **结论先给：契约零变化**——已冻结的接口一个字没动，你不用改任何现有代码。
> 本文讲三件事：这次变化意味着什么、现在可以接的能力清单、一份坑清单。
> 接口权威仍是 `docs/API.md`；下文的「§x.y」均指 `REPORT_TO_P4_A11_ENGINE.md` 对应小节。

## 一、这次变了什么

| 项 | 之前 | 现在 |
| :--- | :--- | :--- |
| 8005 跑在哪 | 5 号的机器，经 Tailscale 访问 | **1 号本机**，主后端经 `127.0.0.1:8005` 直连 |
| 可用性 | 对方机器关机/掉线时，面试接口返 503 | 与 1 号主站同生共死 |
| 接口契约 | — | **零变化**，`/api/v1/*` 的形状一字未动 |

对你意味着三件事：

- **不用改任何已写的代码**，`git pull` 后照常开发。
- 之前因为「引擎不一定在线」而搁置的功能（朗读 / 体态 / 语音转写），**现在可以放心接了**。
- **你连不上、也不需要连 8005 本身**：它只监听 1 号本机的 `127.0.0.1`，局域网都够不着。一切走 8001 的转发口——这是设计如此，不是临时限制。

## 三、坑清单（每条都有人踩过）

1. **50300 不是崩溃**——引擎侧问题一律返 HTTP 503 + `code=50300`，`message` 已写成人话。UI 按「服务暂时不可用，稍后重试」处理，并把 `message` 展示出来；不要当 500 报「系统错误」。
2. **摄像头画面不出浏览器**——体态接口只吃数字关键点（MediaPipe 在本地提取），**不收图片 / 视频 / 音频**。这条边界后端不会放宽。
3. **体态 `score` 可能不存在**——证据不足（帧太少、肩线出画）时引擎**不给分**而不是给低分；前端**不要补 0**，那等于把「镜头坏了」判成「考生体态差」。
4. **ASR 转写要「让人改」**——有错字是正常形态：文本填进输入框、考生确认修改后再提交，别替他直接发出去。
5. **TTS 失败不会给空音频**——引擎不可用时返 503；遇到就静默降级（不播报），别去 `play()` 一个空文件。
6. **超时别设短**——面试相关请求 ≥ `/chat` 540 秒、`/finish` 360 秒（对话层偶发卡住时会把超时预算跑完再收尾，前端掐早了正常场次会被误杀）。这是兜底上限，实测常规是秒级。
7. **轮数从 `/api/v1/config` 拿**——`total_rounds` 随链路变化（7 或 10），别写死；追问期间「第 N 题」不推进是**正确行为**。
8. **音频地址是本站的**——ASR / TTS 返回的 `url` 都挂在 8001 上，直接 `<audio src>` 播放即可，不要拼引擎地址。
