# 运行说明（评委版）

本项目以压缩包整体交付，解压后按下列步骤启动。包内已附带填好密钥的环境文件，无需自行申请大模型账号。

---

## 一、交付包内容

| 目录 / 文件 | 说明 |
| :--- | :--- |
| `backend/` | 主后端、AI 对话与评估层、知识库检索服务、题库与测试 |
| `backend/static/` | 前端构建产物，已挂载到主服务，无需单独启动前端 |
| `backend/.env` | 已填好三家大模型密钥的环境文件，**仅供本次评审使用，请勿对外转发** |
| `backend/dialogue_layer/数据/models/` | 语音识别模型（SenseVoice，约 240MB） |
| `docs/` | 接口文档、开发手册、部署文档与各成员对接文档 |

## 二、启动步骤

**第一步**：确认 `backend/.env` 存在。交付包已附带该文件（仓库中只保留不带密钥的 `.env.example`）。

**第二步**：双击 `backend/start.bat`。

脚本按顺序拉起四个服务，并在窗口打印访问指引：

| 端口 | 服务 |
| :--- | :--- |
| 8001 | 主后端（前端构建产物随此服务挂载） |
| 8003 | 知识库检索服务 |
| 8005 | AI 对话与评估层（面试的出题、追问与五维评分由它承担） |
| 5273 | 演示前端（备用入口） |

**第三步**：浏览器访问 <http://localhost:8001> 开始使用。

## 三、首次启动的准备

首次运行会自动准备依赖与模型，耗时较长，属正常情况：

- 知识库检索的依赖（torch 等，约 2.5GB）在首次启动时自动安装；模型文件（约 4.5GB）在首次检索时下载。
- 语音识别模型随包提供，无需下载。
- 网络受限时可先执行 `set HF_ENDPOINT=https://hf-mirror.com`，再运行启动脚本，走国内镜像。

运行环境建议：内存 8GB 以上，首次启动需联网。

## 四、引擎就绪检查

面试由 AI 对话与评估层（8005）承担，启动后可访问 <http://localhost:8005/health> 确认状态：

- `bank_loaded`：题库已加载
- `scorer_ready`：评分器已就绪（后台线程预热，约需数十秒）
- `llm_configured`：大模型密钥已读到

三项齐全后即可开始面试。该端点恒定返回 200，请以三个字段的取值判断，不要只看状态码。

## 五、若密钥不可用

若密钥失效或额度用尽，可在 `backend/.env` 中把 `DIALOGUE_ENGINE` 置空后重启：

面试改走自有链路（题库策略出题 + 独立评估服务，7 轮制），从注册登录到面试、出报告、
历史记录的完整流程同样可用，仅报告不含成长档案与考后复盘部分。
