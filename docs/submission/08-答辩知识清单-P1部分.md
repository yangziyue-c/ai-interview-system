## 三、架构链路

### 五级数据源链（出题）

```
题库策略 > RAG 语义检索 > 外部面试官服务 > 大模型直连 > 内置 Mock
```

| 级别 | 触发条件 | 失败后的行为 |
| :--- | :--- | :--- |
| 题库策略 | 岗位有题，最高优先级 | 落下一级 |
| RAG 检索 | 题库未命中 | 落下一级 |
| 外部服务 | 配置了 `AI_INTERVIEWER_URL` | 落下一级 |
| 大模型直连 | 配置了 `LLM_BASE_URL` 与 `LLM_API_KEY` | 落下一级 |
| 内置 Mock | 以上全部失败 | 流程仍能走完 |

### 两条面试链路

| 对比项 | 原链路 | 引擎链路 |
| :--- | :--- | :--- |
| 出题与追问 | 题库策略 | AI 对话层引擎 |
| 评分 | P3 评估，按题注入校准锚点 | 引擎逐轮评分，1 到 5 分制 |
| 轮数 | 7 轮 | 10 题（3/5/2） |
| 会话状态 | 全部落库，可恢复 | 引擎内存，重启即丢 |
| 未就绪时 | 不涉及 | 返回 503，不回落原链路 |

## 四、出题规则（原链路）

| 规则 | 内容 |
| :--- | :--- |
| 总轮数 | 1 道开场题 + 6 轮追问 |
| 开场题 | 阶段为开场热身，难度 easy |
| 追问层级 | L1 基础、L2 递进、L3 拓展、答不出时降级引导 |
| L1 触发 | 语义分流：答不出走降级，答得浅才进 L1，实测命中率 100% |
| 第 6、7 轮 | 强制换新题 |
| 收尾题池 | 行为素质题（V5 没有单独的「收尾交流」阶段） |

题目素材四个字段：基础得分点、进阶得分点、三级追问、单题校准锚点。这是题库优先于大模型生成的根本原因。

## 五、评分体系

### 五维权重

| 岗位 | 技术 | 逻辑 | 表达 | 应变 | 匹配 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 后端 | 35 | 25 | 10 | 10 | 20 |

| 测试 | 25 | 25 | 20 | 15 | 15 |
| 算法 | 35 | 30 | 10 | 10 | 15 |
| 系统设计 | 30 | 30 | 15 | 10 | 15 |
| 通用兜底 | 30 | 25 | 20 | 10 | 15 |

权重单一事实源：`app/core/evaluation_weights.py`。CSV 与代码之间有一项测试逐格比对。

### 评分口径

| 规则 | 内容 |
| :--- | :--- |
| 总分 | 五维按岗位权重重算，不采信模型心算 |
| 契约校验 | 五维齐全、数值、0 到 100，否则整体回退兜底报告 |
| 引擎换算 | 1 到 5 分制乘 20 换算为百分制，只在一处完成 |
| 维度缺失 | 用可用维度均值回填，避免雷达图被 0 拖塌 |
| 校准锚点 | 每题的判分尺度，评分前按岗位与题干反查注入 |
| 表达分 | 以 LLM 文本评估为准；语音读数只做展示，不覆盖表达分 |
| 体态分 | 不参与五维评分，只进入报告的展示区 |

## 六、可靠性机制

| 场景 | 机制 | 对外表现 |
| :--- | :--- | :--- |
| 出题某级失败 | 自动降落到下一级 | 流程不中断 |
| 评估失败 | Mock 兜底报告 | 报告仍生成，标注兜底 |
| 引擎未就绪 | 建会话前探测 `/health` 三项 | 503（50300），不回落 |
| 引擎会话丢失 | 收尾本场并置为已结束 | 409，提示重开 |
| 非法状态转换 | 表驱动状态机 | 409 |
| 语音转写失败 | 明确报错 | 503，不返回空文本 |
| 体态证据不足 | 引擎不给分，后端不补默认值 | `available: false` |
| 并发写 | SQLite WAL + 30 秒 busy_timeout | 等待锁而不是立即报错 |
| 老库缺列 | 启动时轻量补列 | 服务可启动 |

错误码：0 成功、40000 参数或业务错误、40100 未登录、40300 无权限、40400 不存在、40900 状态冲突、50000 内部错误、50300 依赖服务不可用。

## 七、决赛新增四项功能

| 功能 | 接口 | 数据来源与口径 |
| :--- | :--- | :--- |
| 设置页 | `GET/PUT /settings` | 6 项偏好，存 `user_settings` 表，无记录返回默认值 |
| 示范作答 | `POST /interviews/{id}/qa/{qa_id}/sample-answer` | 按基础/进阶得分点生成，缓存到 `sample_answers`；题库外返回不可用；进行中返回 409 |
| 表达与表现分析 | 随报告返回 `expression_analysis` | 语音读数来自 ASR 原始响应，体态结果按轮落库；无数据返回 `available: false`，不用模拟值 |
| 职业锚定 | `GET /career-anchor/questions`、`POST /career-anchor/submit` | 20 条陈述（兴趣 10 + 能力 10），按 6:4 加权推荐岗位，只从已开放岗位中选 |

逐题判档：引擎 `/chat` 的 done 帧带 `judge_band`，取最后一轮判定；原链路没有单题分，`needs_improvement` 恒为 `null`。

## 八、隐私与安全边界

| 项目 | 当前做法 | 边界 |
| :--- | :--- | :--- |
| 摄像头 | 浏览器本地提取数字关键点，画面不出浏览器 | 后端只收坐标，不收图片视频 |
| 体态结果 | 只做展示，不进五维评分 | 证据不足时不给分 |
| 简历 | 私有目录，只有鉴权接口可读 | 不经过公开静态目录 |
| 录音 | 上传目录，随机文件名 | 该目录是公开静态目录，没有逐文件鉴权 |
| 密钥 | 只在本机 `.env`，已 gitignore | 不进版本库、文档与 PPT |
| 分享 | 7 天有效，凭码访问 | 不存在与过期返回同一提示，防枚举 |
| 鉴权 | JWT；越权访问返回 404 | 不泄露资源是否存在 |
| 外部大模型 | 评分与示范作答会发送面试文本 | 语音转写是本地模型；隐私说明需写明文本会发送给模型服务 |

## 九、演示风险与兜底话术

| 风险 | 现场话术 |
| :--- | :--- |
| 引擎未就绪 | 「接口会明确返回 503，不静默切换口径；我们切回原链路演示，流程一样完整」 |
| 大模型不可用 | 「示范作答返回 503 而不是空内容；这道题之前生成过，缓存可以直接打开」 |
| 转写不可用 | 「改用文字作答；文字场次的表达分析会如实说明没有语音数据」 |
| 体态无数据 | 「体态需要前端传 `interview_id` 与 `round` 才落库，演示前端还没接这一项，这里只展示报告结构」 |
| 报告生成慢 | 「评估有 30 秒预算，失败也有兜底报告；再等几秒」 |
| RAG 检索慢 | 「重排序在 CPU 上要 20 到 30 秒，所以超时预算给到 60 秒，不按普通接口设」 |
| 页面未接 | 「后端接口已就绪，直接看返回 JSON；前端这一块还在接」 |

## 十一、答辩前必须完成的动作

| 动作 | 原因 |
| :--- | :--- |
| 跑一次 `python -m scripts.eval_consistency` | 否则「评分有证据」只能讲方案，拿不出数据 |
| 把 `01` 到 `04` 材料里的旧数字同步为最新 | 84 项测试、22 个接口、7 张表已经过时 |
| 预生成一道示范作答并确认缓存 | 现场第一次生成要等数秒，缓存命中是毫秒级 |

| 检查四个服务与引擎三项就绪 | 演示前十分钟做，不要到台上才查 |
| 确认内网穿透地址是 HTTPS | http 会被隧道服务拦截 |
