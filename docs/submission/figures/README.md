# 项目插图

《项目详细方案》与《项目简介 PPT》的配图。每张图出两份。

- **PNG** 按 3 倍尺寸导出（约合 300 DPI），任何版本的 Word / PowerPoint / WPS 都可直接插入。
- **SVG** 供需要改字改色的场合使用。PowerPoint 2016 及以上支持插入 SVG，插入后右键
  「转换为形状」即可编辑文字与配色，缩放不损失清晰度。

## 图 1-2 的三点说明

1. 该调查为多选，各项占比之和大于 100%，副标题已注明，避免被误读为单选分布。
2. 原调查共四项主因，第四项为「不了解岗位」50.54%（排第二位）。本图取其中与面试环节
   直接相关的三项，副标题写明这一口径。
3. 三项数值接近，柱长差异相应很小。图的量程上浮 8% 留出余量，未做任何拉伸。

## 重新生成

改 `build_figures.py` 顶部的 `FIGURES` 即可重出。脚本支持四种图形，由配置里的 `type` 决定：

| type | 图形 | 适用 |
| :--- | :--- | :--- |
| `hbar` | 横向条形图 | 占比、数量对比 |
| `flow` | 状态流转 + 流程条 | 流程、状态机 |
| `stacked` | 百分比堆叠条形图 | 多项权重对比 |
| `columns` | 并列卡片栏 | 分类要点 |

```bash
python build_figures.py            # 全部重出
python build_figures.py fig-8-2    # 只重出文件名含该串的图
```

PNG 由本机 Chrome 或 Edge 的无头模式渲染，不依赖 matplotlib 等绘图库，也不需要装任何包。
配色取自演示前端 `frontend_test/css/style.css`，图内文字用微软雅黑。
