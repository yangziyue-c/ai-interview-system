# PPT 插图

《项目简介 PPT》配图的工作目录。每张图出两份：SVG 矢量与同尺寸 PNG 位图。

- **PNG** 按 3 倍尺寸导出（约合 300 DPI），任何版本的 PowerPoint / WPS 都可直接插入。
- **SVG** 供需要改字改色的场合使用。PowerPoint 2016 及以上支持插入 SVG，插入后右键
  「转换为形状」即可编辑文字与配色，缩放不损失清晰度。

## 图 1-2　大学生求职失败的主要原因

横向柱状图，数据取自中国青年报社联合粉笔面向北京 10 所高校 1011 名受访者的调查
（《中国青年报》2025 年 1 月 9 日刊发，记者孟佩佩）。

| 主要原因 | 受访者占比 |
| :--- | ---: |
| 简历不过关 | 50.84% |
| 面试时太紧张 | 49.95% |
| 表达沟通欠缺 | 49.46% |

三点说明：

1. 该调查为多选，各项占比之和大于 100%，副标题已注明，避免被误读为单选分布。
2. 原调查共四项主因，第四项为「不了解岗位」50.54%（排第二位）。本图取其中与面试环节
   直接相关的三项，副标题写明这一口径。
3. 三项数值接近，柱长差异相应很小。图的量程上浮 8% 留出余量，未做任何拉伸。

## 重新生成

改 `build_figures.py` 顶部的 `FIGURES` 即可重出；新增一张图就再加一个配置字典。

```bash
python build_figures.py            # 全部重出
python build_figures.py fig-1-2    # 只重出文件名含该串的图
```

PNG 由本机 Chrome 或 Edge 的无头模式渲染，不依赖 matplotlib 等绘图库，也不需要装任何包。
两处字体与配色：图内文字用微软雅黑，色值取自演示前端 `frontend_test/css/style.css`。
