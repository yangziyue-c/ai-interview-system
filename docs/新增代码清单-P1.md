## 二、功能落点

### 1. 个人资料编辑（`PUT` / `PATCH /api/v1/auth/me`）

| 位置 | 功能 |
| :--- | :--- |
| `backend/app/api/auth.py:59-101` | `update_me` 处理函数。PUT 与 PATCH 双注册指向同一实现；用 `model_dump(exclude_unset=True)` 区分「未传」与「显式传 null」；昵称与目标岗位拒绝空值；换头像后清理旧文件 |
| `backend/app/schemas/auth.py:21-40` | `UpdateProfileRequest` 请求体，四个字段全部可选 |
| `backend/app/schemas/auth.py:42-51` | `UserOut` 增加 `avatar_url` 出参，登录与注册响应同步携带 |
| `backend/app/models/user.py:23` | `users.avatar_url` 列定义（`String(512)`，可空） |
| `backend/app/database.py:138-144` | 老库补列：按项目既有的 `_ensure_column` 机制幂等添加该列 |

### 2. 头像上传（`POST /api/v1/uploads/avatar`）

| 位置 | 功能 |
| :--- | :--- |
| `backend/app/api/uploads.py:44-68` | `upload_avatar`。校验扩展名与体积后落盘至 `uploads/avatars/`；只返回地址，不改用户资料 |
| `backend/app/core/upload_rules.py:33-38` | `looks_like_image` 按文件头判断真实类型，挡住改扩展名混入的非图片内容 |
| `backend/app/core/upload_rules.py:41-48` | `validate_avatar_url` 只接受站内头像目录下的路径，拒绝外部地址与路径穿越 |
| `backend/app/core/upload_rules.py:51-63` | `remove_avatar_file` 换头像时清理旧文件，删除失败仅告警 |
| `backend/app/config.py:59-60` | `MAX_AVATAR_SIZE_MB = 2` 头像体积上限 |

### 3. 报告分享（`POST /api/v1/reports/{id}/share` 与 `GET /api/v1/share/{code}`）

| 位置 | 功能 |
| :--- | :--- |
| `backend/app/models/report_share.py:10-26` | `report_shares` 表模型。外键指向 `interviews`（报告与面试一对一，直连可省一次 join） |
| `backend/app/models/__init__.py:4,10` | 模型注册进统一出口，否则 `create_all` 建表时不会被加载 |
| `backend/app/schemas/report.py:46-53` | `ShareOut` 响应体，含分享码、拼好的完整链接与过期时间 |
| `backend/app/api/reports.py:95-133` | `create_share` 生成分享码。复用尚未过期的链接；`share_url` 按当前请求的 Host 拼接，内网穿透时自动为穿透域名 |
| `backend/app/api/share.py:21-36` | `get_shared_report` 凭码读取报告，返回结构与 `GET /reports/{id}` 完全一致；不存在与已过期返回同一提示；命中时累加访问计数 |
| `backend/app/api/__init__.py:11,20` | 路由挂载点 `/api/v1/share` |
| `backend/app/config.py:62-64` | `SHARE_EXPIRE_DAYS = 7` 分享有效期 |
