### 6. 演示前置条件（容易被当成 bug）

该接口依赖题库与历史面试数据：**题库为空时出题会走 Mock 兜底，题干永远反查不到题库**，
接口只会返回 `notice`（声明「暂无推荐」）。演示前须先导题库并至少完成一场面试：

```bash
cd backend
python -m scripts.import_question_bank --dry-run   # 先看统计
python -m scripts.import_question_bank --yes       # 落库
```

实测（5012 题入库 + 跑满 7 轮）：单场计划响应约 70~130ms，返回 6 个知识点、约 30 道配套练习，
其中第 1、2、6、7 轮（题库原题）贡献知识点，第 3~5 轮的追问文本不在题库、不参与反查。

### 6. 演示前置与验收（容易被当成 bug）

- **图片不会识别是刻意的**（本期不做 OCR）：上传照片返回 `image_pending` 与「请手动填写」提示。
  演示时按「原件已保存、识别能力后续接入」来讲，不要说成「识别失败」。
- **PDF 要用文字版**：WPS / Word 导出的电子简历可以；**扫描件 PDF 与手机拍的照片都没有文字层**，
  会返回 `no_text_layer`。
- **解析依赖**：`pip install -r requirements.txt` 会带上 `pypdf`。没装的机器不会崩——
  接口返回 `failed` + 「服务端未安装 PDF 解析依赖」。
- **人工验证清单**（中文 PDF 无法用 ASCII 夹具覆盖，只能人工跑）：准备 3 份真实简历——
  WPS 导出的文字版 PDF / 扫描件 PDF / 手机拍照 jpg——各上传一次，记录 `parse_status` 与
  三个建议字段是否准确。这一步**尚未执行**（需要真实简历素材）。
