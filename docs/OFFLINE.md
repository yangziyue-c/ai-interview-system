# A11 无大模型离线版

## 启动

1. 安装 Anaconda 或 Miniconda。
2. 双击 `backend/start_offline.bat`。
3. 浏览器打开 `http://localhost:5273`。

首次启动会检查本地 V5 题库；`questions` 表为空时自动导入
`backend/rag/数据/*-v5.json`。已有数据不会被重建或删除。

## 运行边界

离线版只启动两个端口：

| 端口 | 服务 |
| :--- | :--- |
| 8001 | 主后端与 Swagger |
| 5273 | 本地演示前端 |

以下能力在离线版中明确禁用，不会发起外部请求：

- DeepSeek、千问及其他大模型 API
- RAG 语义检索与 8005 AI 对话层
- 8002 外部 AI 评估服务
- 在线语音转写与面试官朗读
- 摄像头体态分析
- 成长档案中的 8005 聚合服务

## 可用能力

- 注册、登录和个人资料
- 5 个岗位的本地题库浏览与文字面试
- 题库规则出题、三级追问和降级引导
- 本地确定性五维报告
- 报告页、问答历史和分享链接

离线评分是确定性的规则报告，不使用语言模型，因此不等同于主版本的语义评分。
需要完整 AI 评分时使用 `backend/start.bat` 和 8005 主版本。
