## 二、主库字段（18 个，JSON 数组，UTF-8）



```
题目ID / 所属岗位 / 题型分类 / 难度等级 / 面试阶段 / 核心关键词 /

考点优先级 / 题目内容 / 基础得分点 / 进阶得分点 /

L1基础追问 / L2递进追问 / L3拓展追问 / 降级策略 /

建议用时(分) / 适用题型基准 / 单题校准锚点 / 关联知识点
```

**建表建议**：



* `题目ID` 为主键（格式如 `JAVA_BACKEND-Q0725`），**贯穿全链路**：RAG 检索命中 → 按原题 ID 回主库取完整素材 → 面试状态机记录当前题 ID → 评估按题 ID 查锚点。

* `关联知识点` 格式：`知识点ID|名称|学习建议`（换行分隔，可拆子表）。

* `单题校准锚点`：评分时判定 "技术水平 / 岗位匹配度" 的具体标准，评估模块用。

## 四、内存索引信息（305 修复后方案，可直接查）

> **背景**：原 ChromaDB 的 HNSW 近似索引出现不同步损坏（sqlite 74011 条 vs HNSW 73706 条，缺口 305 条），加载即报 `Error loading hnsw index`，且任何 chromadb 版本都救不回。已整体改用**内存精确余弦索引**（`MemoryRetriever`，numpy 全量余弦 Top-K），**零近似误差、零漏召**。



| 项          | 值                                                |
| ---------- | ------------------------------------------------ |
| 检索后端       | `MemoryRetriever`（内存精确余弦，接口兼容旧 col 用法）          |
| 文件         | `交付包/向量库/memory_index.npz`（向量矩阵+id）+ `all_records.pkl`（记录本体）         |
| 总条数        | **74,011**（加载时硬断言，不一致直接报错，不会静默少数据）        |
| 向量模型       | BAAI/bge-m3（1024 维，512 token）                    |
| 距离         | cosine（精确计算，非近似）                               |
| 元数据可过滤字段   | 所属岗位 / 题型分类 / 难度等级 / 面试阶段 / 考点优先级 / 对应层级 / 原题 ID |
| 运行时依赖      | **不需要 chromadb**（03/04/05 运行零 chromadb）          |
| 旧库归档        | `交付包/向量库/chroma_db_v2/` 保留为只读归档，不再参与检索 |

## 五、建议的 API 设计（供你封装，2 号会来调）



```
POST /rag/search

入参：{ "query": "学生回答或面试官问题", "job": "Java 后端开发工程师",

\&#x20;       "mode": "select | expand", "top": 3, "level": null }

出参：{ "results": \\\[ { "score": 0.997, "题目": "...", "参考答案": "...",

\&#x20;       "原题ID": "JAVA\\\_BACKEND-Q0725", "层级": "语义变体", "岗位": "...", ... } ] }

mode=select  → 按原题ID去重返回 Top-N 道不同题（出题）

mode=expand  → 命中最高分题后，按原题ID取该题全部层级片段（追问/评分）
```

**状态机对接建议**：面试轮次中保存 `current_question_id`（原题 ID），学生回答后调用 expand 模式取追问素材；评估时用 `current_question_id` 直查主库 18 字段。

### 1. 现成 HTTP 服务（推荐，你几乎不用写代码）

5 号已封装好 FastAPI 服务，直接启动即可：



```
cd 交付包/代码        # ★ 交付包解压到哪就在哪跑，路径自动探测

pip install -r requirements-rag.txt   # 运行 03/04/05 不需要 chromadb（内存索引方案）

```



* `POST /rag/search` — 入参 `{"query":"...","job":"Java 后端开发工程师","mode":"select|expand","top":3,"level":null}`；mode=select 返回 Top-N 道不同题，mode=expand 返回命中题全部层级片段（含 L1/L2/L3、得分点）；查询异常返回 `{"results":[],"error":...}` 不 500

* `GET /health` — 健康检查（返回内存索引总条数 74,011）

* `GET /question/{原题ID}` — 按原题 ID 查主库 18 字段完整素材（降级策略 / 建议用时 / 单题校准锚点等），未命中返回 404

* 模型启动时加载一次（约 10-30 秒，首次启动自动联网下载 bge-m3 + reranker 约 4.5GB，走 hf-mirror），CORS 已放开，4 号前端也可直接调

* 生产部署建议：用 uvicorn 多 worker 或放 Nginx 后面（检索本身无状态，可横向扩展）
