# 评分证据消融实验

目的：固定同一批题目和回答，只切换知识库证据与知识图谱证据，比较四个评分臂。

| 方案 | `A11_KB_EVIDENCE_SCORE` | `A11_KG_SCORE` |
|---|---:|---:|
| 全关 | 0 | 0 |
| 只开知识库 | 1 | 0 |
| 只开图谱 | 0 | 1 |
| 全开 | 1 | 1 |

输入 JSONL 每行格式：

```json
{"sample_id":"001","human_score":3.5,"scores":{"off":4.0,"kb":3.5,"kg":3.8,"both":3.6}}
```

运行：

```powershell
python tools\evaluate_scoring_ablation.py scores.jsonl --output ablation.json
```

输出包含每个方案与人工分的 MAE、Spearman、严重低分召回率，以及相对
`off`、`kb`、`kg` 的 MAE、严重低分召回率、Spearman 差的配对 bootstrap
95% 置信区间。置信区间跨 0 时应按“未观察到稳定增益”解释，不能只挑单个案例；
样本不足或序列为常量时，无法定义的统计量应返回 `null`。
