# ---- RAG ----
# ⚠️ 口径是**两段**，别混成一句「默认关」：
#    · 代码默认关：`app/config.py:402` 的 `A11_RAG = "0"`；
#    · 交付包模板设开：`环境变量.模板.ps1` 写的是 `$env:A11_RAG = "1"`，dot-source 之后即开。
#    部署时用的是模板，所以「按包办事」就是开着的。两个值**都不动**（模板本来就是给部署用的），

# ---- 语音输入（2a / 3b）----
# 本地语音转写。**缺了不影响面试**：`/asr` 返 503 asr_unavailable，
# 文字作答与其余端点一个字节都不受影响（`/health.asr_error` 会写明原因）。
# 但 `A11_ASR` 默认是开的，所以换机器想要语音输入就得装上 —— 它不是可选项。
# 下面 4 条是它的传递依赖，一起锁住（本机实测通过的那一组）：
#   faster-whisper → ctranslate2（推理引擎）/ av（解码任意音频）/ onnxruntime（VAD）
# ⚠️ VAD 那条不是可有可无：语速的分母（净语音时长）与「停顿」次数都靠它量，
#    没有它只能退回「whisper 段跨度之和」—— 实测那段会把静音算进去，
#    同一份音频的语速从 216 字/分掉到 122 字/分（见 app/core/asr.py 的注释）。
faster-whisper==1.2.1
ctranslate2==4.8.2
av==18.1.0
onnxruntime==1.29.0
